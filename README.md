# 00. 푸우서버에 오신 걸 환영해요

**POOH RP SERVER**는 FiveM에서 시민, 직장인, 공공기관 직원 등 자신이 정한 역할로 살아가는 한국어 RP 서버입니다.

처음 접속하는 분은 [01. FiveM 접속 안내](start/01-connect.md)부터, 플레이 중 규정이 궁금한 분은 [08. RP 기본 규칙](community/08-rp-basics.md)부터 확인하세요. 신고와 복구 문의는 [17. 신고·증거·이의제기](support/17-reports-and-appeals.md)에서 접수 방법을 확인할 수 있습니다.

> 운영 규정은 푸우서버의 플레이와 커뮤니티에 적용됩니다. 문서에 나오는 인게임 범죄·체포·벌금은 역할극 안에서 사용되는 기준입니다.
